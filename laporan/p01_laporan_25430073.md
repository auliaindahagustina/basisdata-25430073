## 2. Ringkasan Dasar Teori
Basis data merupakan kumpulan data yang saling berhubungan dan disimpan secara terorganisasi agar dapat digunakan oleh banyak pengguna maupun aplikasi. Pengelolaan basis data dilakukan oleh Database Management System (DBMS), yang membantu mengatur penyimpanan, akses, keamanan, dan pengelolaan data menggunakan SQL.

MariaDB bekerja dengan arsitektur client-server. Server MariaDB menerima permintaan dari berbagai klien, seperti Command Line Interface (CLI) dan phpMyAdmin. XAMPP digunakan sebagai lingkungan praktik yang menyediakan MariaDB dan phpMyAdmin. CLI digunakan untuk menjalankan perintah SQL secara langsung dan menghasilkan skrip yang dapat disimpan serta dijalankan kembali, sedangkan phpMyAdmin menyediakan antarmuka berbasis web untuk berinteraksi dengan basis data.

Dalam MariaDB, akun pengguna ditentukan oleh pasangan nama pengguna dan host. Hak akses perlu diberikan sesuai kebutuhan dengan prinsip least privilege, yaitu setiap akun hanya memperoleh hak yang diperlukan. Selain pengelolaan basis data, Git digunakan sebagai sistem kendali versi untuk mencatat perubahan berkas melalui commit dan menyimpan perkembangan proyek secara bertahap.
